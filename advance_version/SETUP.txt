J&B Family Clinic - advanced version setup
==========================================

Requirements
------------
Node.js 18 or newer.
XAMPP with MySQL running.
Mercury Mail running if you want email delivery. Bookings still work without it.

Install
-------
cd advance_version
npm install

Database
--------
Import advance_version/sql/database.sql.
This DROPS and recreates the jnb_clinic_advance database.
The basic version keeps using jnb_clinic.

Defaults:
  Host: localhost
  User: root
  Password: (empty)
  Database: jnb_clinic_advance

Override with DB_HOST, DB_USER, DB_PASSWORD and DB_NAME if needed.

Run
---
cd advance_version
npm start
Open http://localhost:3000

Tests
-----
npm test

Employee login
--------------
http://localhost:3000/staff

  bryan@localhost.net  / bryan123
  javier@localhost.net / javier123

Patients register at http://localhost:3000/register and sign in at
http://localhost:3000/login.

Email
-----
Nodemailer sends through Mercury SMTP on localhost:25.
Sender: jnb@localhost.net

Allowed local domains:
  localhost
  localhost.net
  localhost.org
  localhost.com

External addresses are blocked before sending. A failed email does not cancel
a booking; the confirmation page reports the status.

The sender must be an existing Mercury user, otherwise Mercury rejects the
message with "invalid or illegal from address". For delivery testing, use an
existing mailbox such as 1234@localhost.net.

Mercury user mailboxes are stored in C:\xampp\MercuryMail\MAIL.
The user list is C:\xampp\MercuryMail\MAIL\PMAIL.USR in the form:
  U;username;Full Name

Environment overrides
---------------------
PORT, SESSION_SECRET, SITE_BASE, DB_HOST, DB_USER, DB_PASSWORD, DB_NAME,
SMTP_HOST, SMTP_PORT, MAIL_FROM.

Notes
-----
Booking window: today through +2 days.
Appointment slots: every 20 minutes, 09:00 to 17:40.
Clinic closed Sundays.
